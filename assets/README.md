# StoryCrush Asset Library

## Source assets

Original, high-resolution, generated, extracted, or editable asset packs belong in:

assets/source/<universe>/

These files are preserved as art-source material and are not automatically included in the production build.

## Runtime assets

Only reviewed, optimized, and game-ready assets belong in:

public/assets/<universe>/

Runtime assets must be resized, compressed, named consistently, represented in an asset manifest, and verified on mobile before integration.

## Current packs

- Fantasy prototype asset pack: assets/source/fantasy/

## Important limitation

The Fantasy pack is a prototype reconstruction derived from a flattened visual reference. Individual assets must be reviewed for edge quality, transparency, scaling, nine-slice margins, and mobile readability before production use.
